# 🌸 Prana Studios — Link Page

> Mobile-first link-in-bio page for a Pilates & Yoga studio.  
> Pure HTML, CSS and JS — no frameworks, no dependencies.

---

## 🇧🇷 Português

### Sobre o projeto

Página de links personalizada para o **Prana Studios**, estúdio de Pilates e Yoga localizado no Upside Araguaia, Jacarepaguá – RJ.

Desenvolvida sem frameworks, com foco em leveza, identidade visual da marca e boa experiência no celular.

### Funcionalidades

- Layout responsivo com hero image e sobreposição dinâmica via JavaScript
- Cards de navegação com ícones SVG customizados
- Link direto para o Google Maps
- Link direto para o WhatsApp com mensagem pré-preenchida
- Rodapé com informações do estúdio
- Fonte serifada elegante via Google Fonts

### Estrutura de arquivos

```
prana-link-page/
├── index.html       # Estrutura e conteúdo
├── style.css        # Estilos e identidade visual
├── script.js        # Lógica do overlap do hero
└── imagem/
    └── fundo.png    # Imagem hero do estúdio
```

### Como usar

1. Clone o repositório
   ```bash
   git clone https://github.com/seu-usuario/prana-link-page.git
   ```
2. Substitua `imagem/fundo.png` pela imagem do seu estúdio
3. Atualize os links de WhatsApp, Maps e redes sociais no `index.html`
4. Publique no GitHub Pages, Vercel ou qualquer hospedagem estática

## 🇺🇸 English

### About

Custom link-in-bio page for **Prana Studios**, a Pilates & Yoga studio located in Rio de Janeiro, Brazil.

Built with no frameworks — just clean HTML, CSS and vanilla JavaScript — keeping it fast and easy to maintain.

### Features

- Responsive layout with dynamic hero image overlap via JavaScript
- Navigation cards with custom SVG icons
- Direct link to Google Maps
- Direct link to WhatsApp with a pre-filled message
- Studio info footer
- Elegant serif typography via Google Fonts

### File structure

```
prana-link-page/
├── index.html       # Markup and content
├── style.css        # Styles and visual identity
├── script.js        # Hero overlap logic
└── imagem/
    └── fundo.png    # Studio hero image
```

### How to use

1. Clone the repository
   ```bash
   git clone https://github.com/your-username/prana-link-page.git
   ```
2. Replace `imagem/fundo.png` with your own studio image
3. Update the WhatsApp, Maps and social links inside `index.html`
4. Deploy to GitHub Pages, Vercel or any static host
